# Texto para entregar no Moodle

Projeto B — individual — Paulo Viana

API de catálogo de produtos, evoluída do backend GT3 para a entrega do Geração Tech 4.0 Full Cycle. Fluxo principal: cadastro e autenticação administrativa, cadastro de categoria/produto, consulta, atualização e filtro por opções.

Repositório público:
https://github.com/PauloVianaTech/projeto-backend-gt4

Execução verde do CI (install, lint, testes e cobertura):
https://github.com/PauloVianaTech/projeto-backend-gt4/actions/runs/43164568035

Evidências: 47 testes aprovados em cinco suítes; cobertura global de linhas 82,43%, ramos 66,5%, funções 82,85% e instruções 80,36%. Docker Compose validado com API e bancos isolados. Smoke k6: 30 requisições, zero falhas e p95 9,05 ms no ambiente local documentado.

O README explica configuração, execução, testes e demonstração. O repositório inclui CONTRIBUTORS.md, docs/desempenho.md, resumo bruto do k6, OpenAPI, ADR, SLO, logs estruturados e métrica Prometheus. O uso de IA foi declarado em docs/ia.md, com decisões e validações sob responsabilidade do autor.
